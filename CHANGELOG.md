# Changelog

## 1.0.0 (2026-10-19)

First public release of both mods.

### token-meter 1.0.0
- Per-prompt input (including cache reads and writes) and output tokens, plus the running session total, above the prompt.
- Keeps bands drawn by other mods: its own row is added under theirs instead of replacing them.
- Tests for the terminal and desktop surfaces.

### session-stats 1.0.0
- Active model, effort level, context-window fill and rate-limit usage with reset times, above the prompt.
- Tests for the terminal and desktop surfaces.
